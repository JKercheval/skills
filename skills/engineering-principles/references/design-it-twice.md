# Design it twice

When a decision has no established precedent, sketch two or three genuinely different approaches and compare them before committing. Building the wrong thing costs more than exploring alternatives.

- A second version of the same idea doesn't count. The alternatives should differ in shape.
- Compare them on the same criteria: simplicity of the interface, how much complexity they hide, how they handle the likely next change.
- Sketches can be cheap: type signatures, a rough prototype, a short written comparison.

**Applies to:** architectural choices with several viable approaches, new kinds of interaction, and decisions that are expensive to reverse.

**Doesn't apply to:** established patterns, bug fixes with a clear target, and changes where constraints leave one viable approach.
